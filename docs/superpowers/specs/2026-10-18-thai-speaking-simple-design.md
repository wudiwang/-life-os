# 泰语30天：轻量跟读版
2026-10-18，Asia/Bangkok。用户要求简化后直接开工，不再审核。本版取代此前复杂方案。

## 学习过程
打开 → 继续学习／选某一天 → 3个关键词 → 4句短对话 → 今天读过了。
每课约3至5分钟；默认同时显示中文、泰文、拉丁字母读音，一个小喇叭播放。只有可选“遮住中文”，不做测验、评分、复习队列、积分、排行榜、催打卡。每五天回看旧表达，仍是相同阅读页面。
课尾记录是用户自报读过，不是已掌握。课号不随日期跳动，可任意回看。记录最近练习日期，使用曼谷时间，失败明确提示。
