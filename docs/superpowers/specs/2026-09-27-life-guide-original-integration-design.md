## 目标与范围

在现有个人管理系统新增“人生指南”独立入口，本地保留 HowToLiveBetter 原仓库，接入其原版阅读、目录、搜索、筛选和长文功能。不重写为另一套阅读器，不把指南导入用户的私人知识笔记或自动转成目标、习惯及健康建议。

已选择的方案：原版静态内容 + 现有系统内的轻量入口。相比统一风格重做，它保留原版行为，改动较小；代价是正文仍使用原版样式，更新时需要重新核查上游。

## 组成与数据流

1. **原始仓库**：克隆到 `.vendor/howtolivebetter/`，检出固定提交；排除在父仓库 Git 跟踪之外。保留原始文件与历史，不在原始副本上混入个人数据。
2. **本地发布快照**：审阅上游离线构建逻辑后，在独立生成流程中内嵌正文和长文，输出到 `public/life-guide/`。原文与索引取自同一提交；保留 LICENSE 和记录仓库、提交、生成时间及适配项的来源清单。公开目录只放阅读所需产物，不包含 `.git`、凭据、代理规则或私人档案。
3. **模块外壳**：新增 `src/pages/LifeGuide/LifeGuidePage.jsx`，注册到 `src/pages/registry.js`，在 `src/lib/constants.js` 的共用导航新增“人生指南”。PC 侧栏和手机抽屉使用同一入口。
4. **展示**：通过 sandbox iframe 的本地 `src` 加载单文件阅读页，不使用 `srcdoc`，避免其 URL 与 history 行为限制。正文和 README 引用的顶层长文内嵌，核心阅读运行时不依赖 GitHub、Google Fonts 或 CDN；保留原版目录、搜索、筛选、主题切换及长文入口。上游核实记录、引用原始材料和下载站点仍作为外部资料，不宣称所有出处已离线保存。

本模块不读写业务数据库，无 SQL 迁移，不需要 `.env`、AI 接口、Telegram 或新账户。首次打开仍需本地开发服务或现有网站提供静态文件；不新增 Service Worker，也不宣称整个系统已经支持首次离线访问。

## 隐私与隔离

- 移除 Google Analytics、搜索词/阅读事件上报、在线字体与预连接，以及广告内容和对应布局；保留正文引用，不因去广告改动指南观点。
- 阅读页设置限制性内容安全策略：不允许后台网络连接或外部脚本；只放行实际所需的内联脚本、样式及本地内嵌资源。通过网络检查验证无自动第三方请求。
- iframe 只允许脚本和用户主动打开的参考链接，不允许 same-origin、顶层页面跳转、表单提交或访问父页面。父应用不向阅读页传任何私人数据或令牌。
- 原版 localStorage 已有异常保护；沙箱下保留安全降级，主题以会话内状态运行，不为主题记忆而放开父应用存储访问。跨次打开不保证保留指南主题选择，主题切换本身必须可用。
- 离线构建可能把标题/README 等链接改为线上地址；适配后保留标题及正文的本地阅读行为。外部链接只在用户点击时新窗口打开，使用 `noopener`、`noreferrer`，不得把外部页面载入阅读 iframe。核实目录跳转、筛选、返回时的 history 调用，在沙箱中不能因异常导致页面失效。
- 不提供绕过隔离的本地“裸开阅读器”入口。页面提供重试和原项目链接作为故障回退；访问原项目属于外部网站访问，需在按钮旁明确区分。
- 模块注明外部参考资料、固定版本及适用范围以原文为准，不暗示其中医疗、法律、投资等内容已经针对用户情况核验。

## 电脑、手机与故障处理

外壳沿用项目色板及 inline 样式，使用现有 `useIsMobile` 调整间距、按钮排列和阅读高度。原版内部保留响应式布局；检查窄屏搜索、筛选、长文关闭与返回，不产生页面级横向溢出。

区分准备中、加载成功和加载失败/超时，失败时显示可理解的提示与“重试”，不只留空白 iframe。采用内容就绪信号时，仅接受当前 iframe 发出的固定状态消息，不接受任意窗口的数据指令。切走模块不会阻断系统其他页面。

## 更新与不做事项

首次为固定快照；不新增自动拉取、定时任务或后台更新。以后用户要求更新时，先检查上游差异及隐私适配是否仍有效，再生成新快照并验证。构建失败应停止替换，保留上一份可用快照。

本次不做收藏/笔记联动、AI 解读、提醒、账户同步、自动采纳建议、其他模块重构或数据库改动。不启用旧简报或改动22:07归档任务。不 push、不部署；本地提交不会触发 Vercel，push 需要另行明确授权。

## 验收

1. Git 原始副本 origin 和 HEAD 与上述仓库及固定提交一致，来源清单、许可证存在；正文/章节/长文数量与固定版本一致，不靠手填数量证明完整。
2. 加载、目录跳转、已知词搜索、无结果提示、筛选/清除筛选、长文打开/关闭、主题切换均能操作。
3. 电脑和约390px手机视口分别检查阅读、滚动及控件可达性；菜单能进入并返回其他模块。
4. 自动化检查及浏览器网络检查不出现 GA、Google Fonts、广告请求或搜索词外发；阅读页不能访问父页面存储，现有用户数据不变。
5. 验证缺失资源/加载失败回退；加载完成后禁用外网，已内嵌内容仍可搜索阅读。外部引用需网络属于预期。
6. 新增适配/产物检查测试通过；运行 `npm run build` 和 `npx eslint src api`，如有既存失败须分清来源并报告，不掩盖失败。
7. 交付本地可运行结果、上游版本和验证记录；只有验证通过才称模块接入完成，未部署则明确说明。
