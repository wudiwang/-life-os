# 健康塑形计划（第 1 期 · 12 周）

> 2026-11-03 制定。当前主线：**健身 + 饮食**两项日常；护肤只做防晒，健康数据每月体检一次。其余以后再加。
> 后续任何会话（云端 / 本机 / 大仙）做饮食或训练分析时，以本文的目标和规则为准；数字变化时更新本文。

## 每日目标

| 项目 | 目标 | 依据 |
|---|---|---|
| 热量 | **约 1,900 kcal** | 基础代谢约 1,800；在家办公 + 每周 3 练 + 8,000 步，总消耗约 2,400–2,500，缺口约 500 |
| 蛋白质 | **150g**（约 1.6g/kg 体重） | 减脂期保肌肉的关键；每餐 ≥ 35g |
| 净碳水 | **≤ 30g** | 生酮；蔬菜照吃 |
| 脂肪 | 约 130g（补足剩余热量） | 橄榄油、牛油果、坚果、鱼、蛋黄 |
| 水 | 3L | 尿液保持淡黄色，防肾结石 |
| 步数 | **8,000** | 在家办公最容易缺；饭后走 15–20 分钟 |

**方案 B（皮疹确诊为生酮疹，或训练表现持续很差时）**：热量、蛋白不变，净碳水放宽到 80–100g，碳水集中在午餐和训练后（米饭、红薯、燕麦、香蕉）。

## 训练（每周 3 次全身力量，A/B 交替，如周一 A、周三 B、周五 A，下周反过来）

| A 日 | B 日 |
|---|---|
| 腿举 或 高脚杯深蹲 3×10 | 高脚杯深蹲 3×10 |
| 哑铃卧推 或 器械推胸 3×10 | 坐姿划船 3×10 |
| 高位下拉 3×10 | 哑铃肩推 3×10 |
| 哑铃罗马尼亚硬拉 3×10 | 臀推 3×12 |
| 平板支撑 3×30 秒 | 侧平举 3×12、死虫 3×10 |

- 每次约 50 分钟：热身 5 分钟 → 力量 35–40 分钟 → 可选坡度快走 10 分钟。
- 强度：每组做完还能再做 2–3 次。进步方式：每个动作所有组都做满 12 次，下次加一档重量。
- 第 1–2 周每个动作只做 2 组、重量轻，先学动作；建议请 2–3 次私教课学动作要领。
- 喝酒或熬夜后的第二天不练力量，改为走路。

## 补剂要点

- **柠檬酸钾**：可降低结石风险，可以吃；补剂里的钾合计控制在每天 1,000mg 以内，第一次抽血查血钾和肌酐。服用降压药（ACEI/ARB/保钾利尿剂）前要问医生。
- **镁**：需要补。每天元素镁 200–400mg，睡前吃；看清标签上的「元素镁」含量，拉肚子就减量。
- **鱼油**：够用。每天 EPA+DHA 合计 500mg–1g，看标签上 EPA+DHA 的含量而不是「鱼油 1000mg」。深海鱼不必买三文鱼，泰国的 ปลาทู（短鲭鱼）、沙丁鱼罐头便宜又好。

## 互动机制

**用户提供**

| 频率 | 内容 |
|---|---|
| 每天（晚上一条汇总即可） | 早上空腹体重；每餐食物照片（包装食品第一次拍营养成分表）；训练内容（动作 × 重量 × 次数，或「休息」）；步数；一句感受（饿不饿、累不累、疹子） |
| 每周日 | 腰围（肚脐一圈）；苹果手表一周截图；动态血糖周报截图（在戴的话） |
| 每月 | InBody 报告；正面 / 侧面 / 背面照片各一张（同一地点、同一光线）；抽血报告 |

**教练反馈**

- 每天：热量、蛋白质、净碳水的估算 vs 目标；明天最该调整的一件事；下次训练的重量。
- 每周：7 天平均体重和腰围趋势，按下方规则调整。
- 每月：阶段复盘，检查体脂率、肌肉量、血液指标。

**调整规则**

| 情况 | 调整 |
|---|---|
| 连续 2 周 7 日平均体重下降 < 0.3kg | 每天少 150 kcal（优先减脂肪），或步数 +2,000 |
| 单周下降 > 1.2kg（第 1–2 周掉水分除外） | 每天加 150 kcal |
| 训练重量连续 2 周停滞、很累 | 检查睡眠和蛋白质；仍不行考虑方案 B |
| 蛋白质连续 3 天 < 120g | 加一份乳清蛋白或一盒鸡胸肉 |

## 12 周预期

体重约 90 → 82–84kg（前 1–2 周含 1–3kg 水分）；腰围小 6–10cm；体脂率约 30% → 24–25%；力量从零起步明显上涨。腹肌线条一般要到 15% 左右体脂才清楚，需要再一到两期。

## 每月体检

每月：血脂四项、肝功能、肾功能（肌酐、尿素氮）、尿酸、电解质（钾）、空腹血糖 + InBody。
每 3 个月加：ApoB、糖化血红蛋白、空腹胰岛素。
抽血前一天不喝酒、不做大重量训练，空腹 8–12 小时。
