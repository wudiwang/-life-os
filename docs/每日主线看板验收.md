# 每日主线看板

## 本次范围

- 保留 PM 工作、交易研究、长期能力与习惯三大主线，原始内容不覆盖，长计划通过 `#plan=<journal_threads.id>` 打开。
- 英语、泰语 12 周规划保存于现有 journal_threads，每项仅一条；每周六天的日常练习复用 work_todos，关联原计划。
- 首页支持优先级、预计分钟、完成标准、关联计划、日期调整、重复星期、完成/撤销、当日跳过、可选反馈及手动实际分钟。
- 按泰国时间切日。todo_day_entries 以 todo_id/log_date 唯一，重复任务不改模板的完成状态。单次任务保持 work_todos 兼容状态；旧工作页的状态仍为单次任务权威。
- 历史视图仅展示真实记录和原有带完成时间的事项，不从当前模板猜过去计划。反馈按日保存，未反馈不猜原因。
- 记录与复盘是规则式轻量摘要，不是 AI 重新推断，不把完成数量当收益。无外部通知或主账号发送。

## 数据与上线

执行 v11_daily_actions.sql 兼容扩展及两语言重复练习种子；v12_plan_links.sql 仅将已核实的既有 PM/表达待办关联现有主线，不改标题或完成情况。
既有主线原文、旧待办及生活概览保留。没有实际可验证关联的事项保留“未关联原计划”，不强行绑定。
新增按日记录纳入设置的 JSON 备份。当前沿用项目已有数据库访问模型，没有在本轮实现独立用户鉴权。
