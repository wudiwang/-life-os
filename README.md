# 🌱 人生 OS · 个人管理系统

> 记录生活 · 记录感悟 · 记录目标 · 记录健康 —— 用数字化的方式看清自己，过好这一生。

## 这是什么

一个部署在你自己 Vercel + Supabase 上的个人管理系统，把"我这个人"数字化：

| 模块 | 干什么 |
|---|---|
| 🏠 人生看板 | 今日概览 + 人生阶段面板 + 检查点提醒，一屏看清当下 |
| 📔 每日一记 | 每天一分钟：心情 + 几句话 + 美好瞬间，附心情曲线 |
| ❤️ 健康 | 体重/血压/心率等指标趋势图；体检报告上传永久保存 + AI 解读 |
| 🔁 习惯 | 习惯打卡、连续天数、周目标完成率 |
| 🎯 目标 | 年/季/月/短期目标，里程碑检查点（到点录入数据自检），每日过程记录，结项复盘 |
| 💼 工作 | 每日待办、工作日志、职责档案、人际地图（汇报关系/相处姿态） |
| 🧭 探索世界 | 美食/旅行/经历/认知的记录，生活的美好清单 |
| 🧠 第二大脑 | Markdown 知识笔记 + 分类标签 + 全文搜索，外挂大脑 |
| 💞 情感关系 | 亲情/友情/爱情的重要之人档案 + 互动记录 + 生日/失联提醒 |
| 🤖 AI 分析 | Claude 读取你的数据，给出评价、建议与提醒，历史留档 |
| ⚙️ 设置 | 连接状态、全量 JSON 备份导出 |

## 技术架构（与领航项目一致）

React 19 + Vite 前端（Vercel）+ Supabase(Postgres) + Vercel Serverless（`api/*.js`）+ Claude API。
纯 inline 样式，zustand 管全局态，无 react-router（App.jsx switch 切页）。

**双模式数据层**：未配置 Supabase 密钥时自动进入演示模式（数据存浏览器 localStorage），全部功能可用；填好 `.env` 即切换云端永久保存，页面代码零改动。

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173，无需任何密钥即可体验（演示模式）
```

正式部署（Supabase + Vercel + AI）见 **[部署指南.md](./部署指南.md)**，约 15 分钟。
